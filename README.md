# SupaMe 🎨

**SupaMe** — это десктопный редактор мемов с локальным веб-интерфейсом. Приложение
работает офлайн: все данные хранятся в вашем браузере (IndexedDB), сервер запускается
только на `127.0.0.1`, никакого облака, аккаунтов и телеметрии.

Собирайте мемы «на коленке»: загрузите картинку, добавьте подпись, комиксный «баббл»
или нарисуйте стрелку карандашом — и экспортируйте готовый мем в PNG, JPEG или WebP.

> **Чем это не является:** это не Electron-приложение и не облачный сервис. SupaMe —
> обычный Vite/React-бандл, который раздаёт лёгкий Node HTTP-сервер из папки `desktop/`,
> а в системном трее появляется иконка для управления. Отсюда — минимальный размер,
> отсутствие тяжёлого рантайма и полная работа из коробки на Linux, macOS и Windows.

## Возможности

### Холст (Canvas)

| Возможность | Описание |
|---|---|
| Готовые размеры | Пресеты: **Квадрат** 1080×1080, **Портрет** 1080×1350, **Сторис** 1080×1920, **Ландшафт** 1200×630 |
| Произвольный размер | От 100×100 до 4096×4096 px в правой панели |
| Фон | Сплошной цвет, **прозрачный** (шахматная подложка в редакторе) или **изображение** |
| Зум | Колесо мыши (к курсору) + кнопки «+»/«−»/«100%»/«Вписать», диапазон 25–400 % |
| Привязка (снапы) | Голубые направляющие к краям и центру холста при перетаскивании |

### Объекты

#### 🖼 Изображения
- Загрузка: через диалог, **drag & drop на холст**, вставка из буфера обмена (Ctrl+V).
- Автовписывание в холст с сохранением пропорций (до 70 % холста).
- Трансформация: масштаб (с сохранением пропорций), поворот (привязка к 45°), отражение по
  горизонтали/вертикали.
- **Обрезка** в пикселях исходника (удобно «обрезать нижнюю половину» для шаблонов) +
  кнопка сброса.
- **6 фильтров**: яркость, контраст, насыщенность, размытие, ч/б, сепия — с отдельным
  сбросом. Все редактируются на лету.

#### ✍️ Текст
- Любой текст на холсте, перенос по словам, автоподбор высоты.
- **6 шрифтов**: Oswald, Roboto Condensed, Inter, Marck Script (рукописный) и JetBrains
  Mono — с поддержкой кириллицы, плюс мемный латинский **Anton** (для мемов на английском).
- Размер, жирный/курсив, цвет, **обводка** (классический белый с чёрной канвой), **тень**
  (цвет/сдвиг/размытие/плотность), регистр (ЗАГЛАВНЫЕ/строчные), выравнивание,
  межстрочный и межбуквенный интервалы.
- Быстрые действия: **«Подпись сверху / снизу»** в один клик и пресет **«Мемный стиль»**
  (Oswald, жирный, капс).

#### 💬 Бабблы (комиксные облачка)
- 5 форм: скруглённый прямоугольник, овал, **облачко**, **«крик»** (звезда), простой
  прямоугольник.
- Настраиваемые заливка, граница (цвет/толщина), радиус углов, отступ текста.
- **Тянущийся хвостик**: у выделенного баббла за синюю ручку — любой длины/направления;
  настраиваются основание и кривизна.
- Текст внутри с автоуменьшением шрифта (`autoFit`), чтобы не вылезал за границы.

#### 🔺 Фигуры и штрихи (Paint)
См. [раздел про инструменты рисования](#инструменты-рисования-paint).

### Слои и правки

- **Панель слоёв**: переименование через тип объекта, видимость 👁, блокировка 🔒,
  поднять/опустить, дублировать, удалить.
- Слои в контекстном меню и горячими клавишами (Ctrl+]), передний/задний план.
- **Мультивыделение** (Shift+клик) → выравнивание по 6 направлениям и **распределение**
  (3 и более объекта).
- **История undo/redo** на 100 шагов; серии изменений слайдерами/цветом объединяются в
  одну запись; стрелки двигают объект на 1 px (Shift — на 10 px).
- Контекстное меню правой кнопкой: дублировать, копировать/вставить, слой, блокировка,
  скрыть, удалить.

### Проекты и сохранение

- **Автосохранение** — через ~1,2 с после изменений + при закрытии вкладки. Статус в
  шапке и в статус-баре: «Сохранено / Сохранение… / Есть изменения».
- Диалог **«Проекты»**: миниатюры, открытие, переименование, копия, удаление, импорт.
- **Экспорт мема**: PNG / JPEG / WebP, масштаб 1×/2×/3×, качество (для JPEG/WebP),
  прозрачный фон (кроме JPEG), своё имя файла (по умолчанию — транслитерация имени проекта).
- **Проект в файл** (`*.supame.json`): единый JSON с вложенными изображениями в base64 —
  можно перенести на другой компьютер или отдать коллеге. Импорт из того же файла.

### Рабочая среда

- Экран приветствия и подсказки при пустом холсте («Перетащите изображение сюда»).
- Тост-уведомления.
- Статус-бар: размер холста, зум, число объектов, статус сохранения, подсказки.

## Как это устроено

```
React 18 UI  ──►  zustand-сторы  ──►  Konva Stage (react-konva)
(TopBar, LeftPanel,   useEditor: проект,   объекты: Image, Text, Bubble,
 RightPanel, Dialogs,  объекты, undo/redo) Shape; выделение, снапы, зум,
 Toast, Welcome)        useUi: диалоги,     трансформер, Paint-инструменты,
                        инструменты, цвета  контекстное меню
      │                       │                         │
      └───────────────────────┴─────────────────────────┤
                          │                             │
                          ▼                             ▼
        автосохранение  ────────────►  IndexedDB «supame-db»
        (lib/autosave, ~1,2 с)          projects (миниатюры) · assets (blobs)

        Экспорт: offscreen-рендер без хелперов
        (lib/stageCapture) ────►  PNG / JPEG / WebP

  desktop/  ──►  Node-процесс: раздаёт собранный dist/ (без Electron)
    server.mjs    статический HTTP-сервер: порт 5180 → 5181…, открытие браузера
    tray.mjs      иконка в трее: «Открыть» / «Выход» (systray2)
    launcher.mjs  консольный режим: сервер + браузер (Ctrl+C — выход)
```

Ключевая идея: **вся логика живёт в браузере**. Node-процесс нужен только чтобы раздавать
статику и держать иконку в трее; данные — в IndexedDB конкретного браузера. Благодаря этому:
- приложение работает полностью офлайн и ничего не отправляет наружу;
- перезапуск ничего не теряет (автосохранение уже в базе);
- «сервер» не требует админских прав и умирает вместе с треем.

Единый экземпляр: если SupaMe уже запущен (порт 5180 отвечает), новый процесс не поднимает
второй сервер, а просто открывает браузер на существующий адрес.

## Технологии

| Слой | Стек |
|---|---|
| UI | [React 18](https://react.dev), TypeScript 5.6 |
| Сборка | [Vite 5](https://vite.dev) (`vite.config.ts`, порт dev-сервера 5180) |
| Холст | [Konva](https://konvajs.org) 9.3 + [react-konva](https://konvajs.org/docs/react/) 18 |
| Состояние | [zustand](https://github.com/pmndrs/zustand) 4.5 (`src/store/`) |
| Хранилище | Индексная БД браузера (indexedDB), без зависимостей (`src/db/idb.ts`) |
| Шрифты | [@fontsource](https://fontsource.org): Anton, Oswald, Roboto Condensed, Inter, Marck Script, JetBrains Mono |
| Режим приложения | Node HTTP + [systray2](https://www.npmjs.com/package/systray2) (иконка в трее) |

Требования: **Node.js 20+** (в `supame.sh` проверка версии автоматическая; на Windows
`supame.cmd` проверяет наличие Node) и `npm`. Что-либо ещё не нужно.

## Установка и запуск

### Быстрый старт (рекомендуется) — одна команда

Скопируйте репозиторий и запустите скрипт. Он сам сделает всё: проверит Node.js,
установит зависимости (только при первом запуске), соберёт приложение (только если нужно)
и запустит иконку в трее.

```bash
# Linux / macOS
./supame.sh

# Windows (в cmd или PowerShell)
supame.cmd
```

Флаги:

```bash
./supame.sh --rebuild   # принудительно пересобрать (после изменений в коде)
./supame.sh --browser   # без трея: сервер + браузер в терминале (Ctrl+C — выход)
supame.cmd --rebuild    # Windows, пересборка
```

Что происходит: поднимается локальный сервис, в трее появляется иконка с меню
**«Открыть»** и **«Выход»**. При первом запуске редактор открывается в браузере сразу.

> Если графической среды нет (например, чистый сервер), трей недоступен — приложение
> честно сообщит об этом и просто откроет редактор в браузере (консольный режим).
> PID и лог запуска пишутся в `.supame.pid` / `.supame.log` (в корне репозитория, в git не
> попадают); если SupaMe уже запущен, скрипт сообщит адрес и выйдет.

### Ручная установка

```bash
npm install        # установить зависимости
npm run build      # собрать production-бандл в dist/
npm run start      # запустить: иконка в трее («Открыть» / «Выход»)
```

Либо без трея — сервер и браузер в одном терминале:

```bash
npm run browser    # сервер + браузер; Ctrl+C — выход
```

## Режим разработчика

```bash
npm install
npm run dev        # Vite dev-сервер с HMR → http://127.0.0.1:5180
```

- Dev-сервер (Vite) и промышленный сервер (`desktop/server.mjs`) используют один порт
  5180; при занятости Node-сервер переходит на следующий свободный (5181, 5182…).
- Типичный цикл: правки в `src/` → `npm run typecheck` (TS) → `npm run build`.
- Тестов нет (в `package.json` нет test-скрипта); «проверкой» служит
  `npm run typecheck` и ручная проверка в браузере.
- Иконку трея при необходимости перегенерируют: `npm run icon`
  (пишет `desktop/tray.png`).

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Z` / `Ctrl+Shift+Z`, `Ctrl+Y` | Отменить / повторить |
| `Ctrl+S` | Принудительно сохранить |
| `Ctrl+E` | Открыть диалог экспорта изображения |
| `Ctrl+D` | Дублировать выделенные объекты |
| `Ctrl+A` | Выделить все (разблокированные) объекты |
| `Ctrl+C` / `Ctrl+V` | Скопировать / вставить из внутреннего буфера |
| `Ctrl+]` / `Ctrl+[` | Слой выше / ниже |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | Увеличить / уменьшить / 100 % |
| `Delete`, `Backspace` | Удалить выделенное |
| `Esc` | Снять выделение, инструмент «Выделение», закрыть диалоги |
| `← ↑ → ↓` | Сдвиг на 1 px (с `Shift` — на 10 px) |
| `V` `P` `N` `L` `R` `O` `F` | Быстрый выбор инструмента: выделение, карандаш, перо, линия, прямоугольник, овал, заливка |

Горячие клавиши не срабатывают, когда фокус в поле ввода (текст, числовое поле и т. п.).

## Инструменты рисования (Paint)

Плавающая панель над холстом, слева:

| Инструмент | Клавиша | Что делает |
|---|---|---|
| Выделение | `V` | Перемещение, трансформация, мультивыделение (Shift+клик) |
| Карандаш | `P` | Произвольная линия (`tension: 0`) |
| Перо | `N` | Сглаженная кривая (`tension: 0.5`) |
| Линия | `L` | Прямая; с зажатым **Shift** — шаг 45° |
| Прямоугольник | `R` | Прямоугольник с заливкой/обводкой и радиусом углов |
| Овал | `O` | Эллипс |
| Заливка | `F` | Перекрасить фигуру, баббл, текст или сам фон холста |

Рядом — выбор цвета обводки/карандаша, цвета заливки и толщины штриха (1–40 px).
Любую нарисованную фигуру в правой панели можно переключить на другой тип
(прямоугольник/овал/треугольник/линия/карандаш/перо), менять заливку («без заливки»),
обводку и радиус углов. `Esc` отменяет недорисованный штрих.

## Встроенные шаблоны

Вкладка **«Шаблоны»** в левой панели даёт 5 стартовых раскладок (1080×1080):

| Шаблон | Что внутри |
|---|---|
| **Классика** | Фото + верхняя и нижняя подписи |
| **Пузырь** | Фото + одно облачко с хвостиком |
| **Диалог** | Две реплики в бабблах сверху/снизу |
| **Комикс 2×2** | Четыре кадра с подписями |
| **За и против** | Два блока «✕» / «✓» рядом с фото |

Шаблон создаёт **новый проект** (текущий остаётся в списке). Место фото занимает
лицензионно чистая серая заглушка «Замените изображение» — просто замените её своей
картинкой и поправьте подписи.

## Данные: где и в каком формате

### Локальное хранилище (IndexedDB, база `supame-db`)

| Хранилище | Что лежит |
|---|---|
| `projects` | Записи проектов: id, имя, даты, миниатюра (dataURL), JSON-данные холста и объектов |
| `assets` | Вложенные изображения: id, имя, mime, blob |

Всё живёт **только в вашем браузере**. Очистка данных браузера удалит проекты — для
постоянного хранения используйте экспорт проекта в файл.

### Формат файла проекта `*.supame.json`

Экспорт через кнопку **«В файл»** в шапке. Это JSON вида:

```json
{
  "version": 1,
  "app": "SupaMe",
  "name": "Название проекта",
  "data": {
    "version": 1,
    "canvas": { "width": 1080, "height": 1080, "background": { "type": "color", "color": "#FFFFFF", "transparent": false } },
    "objects": [ ]
  },
  "assets": [ { "id": "…", "name": "photo.jpg", "mime": "image/jpeg", "dataUrl": "data:image/jpeg;base64,…" } ]
}
```

Все изображения вшиты в файл (base64), поэтому `.supame.json` самодостаточен для переноса
или бэкапа. Импорт («Из файла» в шапке или в диалоге «Проекты») проверяет поле `app === "SupaMe"`
и при конфликте id ассетов назначает новые.

### Экспорт изображения

Диалог экспорта (Ctrl+E): **PNG / JPEG / WebP**; масштаб 1×, 2×, 3× (примерный размер
показывается сразу); качество 30–100 % (JPEG/WebP); прозрачный фон (кроме JPEG).
Экспорт рендерится в offscreen-сцену, поэтому хелперы (трансформер, снапы, ручки бабблов)
в картинку не попадают, даже если в этот момент что-то выделено.

## Известные ограничения

- **Хранилище привязано к браузеру и профилю**: проекты в IndexedDB не «разъезжаются» между
  браузерами и устройствами — переносите их файлом `*.supame.json`.
- **Undo/redo — память сессии**: история (100 шагов) не сохраняется между перезапусками.
- Шрифт **Anton** содержит только латиницу (для мемов на английском); остальные шрифты — с
  поддержкой кириллицы.
- JPEG не поддерживает прозрачность: опция «Прозрачный фон» скрыта для этого формата.
- Dev и prod используют порт **5180**: если он занят сторонним процессом, dev-сервер Vite
  выберет другой порт автоматически, а Node-сервер попробует 5181, 5182 и т. д.

## Лицензия

Сублицензионных файлов в репозитории нет (LICENSE отсутствует), пакет помечен
`"private": true`. Встроенные шаблоны используют только генерируемые на лету нейтральные
заглушки — без сторонних изображений. Перед распространением добавьте файл лицензии по
своему усмотрению.
